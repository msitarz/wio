# The directive grammar

## Purpose

A template's sections need one grammar that says what each section must hold.

## Intent

Parse a heading's directives into typed values in `wio.formats`, with the
optional quoted `pattern`, and document the grammar in
`src/wio/formats/README.md`. Finding items in a section is deferred to the
contracts Work.
