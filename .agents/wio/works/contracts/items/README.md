# Items of a section

<!--

## Purpose

A contract's items, such as its criteria, carry ids that records and reviews
cite, so wio must find them the same way everywhere.

## Intent

Find the items of a section, apply `items>=N` and `pattern`, and check that ids
are unique, matched by one section and free of whitespace and commas. Settles
how wio finds items.
