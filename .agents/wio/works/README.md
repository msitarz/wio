# The Works of wio

The contracts of the Works that build wio live here, one directory for each
Work, nested under the Work it belongs to. A file in this directory is a Work
only when it starts with a `wio` metadata block ([Which files are
Works](../../../docs/concepts.md#which-files-are-works)), so this README is not
one.

A contract is deleted once its guarantees live in the documents, the stubs and
the tests, so this directory may hold none; the README keeps it in git. How a
contract is retired is in
[the workflow](../../../docs/workflow.md#retiring-a-contract).
