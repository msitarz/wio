Leave out of a `README.md` what a stub, docstring, signature, test or config in
its directory already states, such as fields, options, names and counts, and
link to it; a guarantee that one of them states is kept by that link.

Why: A restatement goes stale the moment the source changes and hides the
reasons and cross-cutting guarantees that only the README can carry.
