code = "WRT002"
name = "diagrams-from-current-source"
-->

Draw a diagram from the current source and documents and check the whole
diagram against them, and in a contract name the revision it was checked
against; that it renders is no evidence that it is correct.

Why: A diagram drawn from memory misleads every later reader who trusts it, a
contract's reviewer needs the revision to judge it, and rendering proves the
syntax, not the design.
