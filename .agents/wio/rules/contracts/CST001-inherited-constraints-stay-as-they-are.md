State only the constraints this Work adds: never restate a constraint it
inherits, and never weaken one; amend the parent instead.

Why: Inherited constraints appear with the contract in every bundle, so a
restated copy only drifts, and a child that weakens a shared guarantee breaks it
for the whole parent without anyone deciding so.
