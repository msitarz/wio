Draw the before state from the current source or contracts, name the revision it
was verified against, and check the whole diagram against the source and the
contracts; that it renders is no evidence that it is correct.

Why: A diagram drawn from memory misleads every later stage that trusts it, and
rendering proves the syntax, not the design.
