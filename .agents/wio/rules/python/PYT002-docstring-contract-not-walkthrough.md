Write a Google-style docstring for every module, class and function, private
helpers too, describing purpose, observable guarantees, boundaries and failures.
Omit implementation walkthroughs and facts evident from the signature, and refer
to helpers for their own guarantees instead of repeating them.

Why: Concise contract-focused docstrings stay accurate as code evolves and keep
context tight for people and agents.
